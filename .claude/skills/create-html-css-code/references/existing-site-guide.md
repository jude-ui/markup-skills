# Existing Site Guide

기존 사이트 화면 소스를 긁어온 로컬 페이지에서 작업할 때 참고할 가이드. **다른 가이드와 다르게 적은 곳은 이 문서를 따른다.**

- **사이트 CSS 목록** — 작업 전에 페이지가 불러오는 사이트 CSS 를 전부 파일로 받아 클래스·id·요소 셀렉터 목록을 뽑는다. 접근할 수 없는 CSS 는 사용자에게 다운로드를 요청한다. **기억에 의존하지 않고 이 목록과 대조한다**
- **클래스명** — 새 마크업에 쓰는 모든 클래스명을 목록과 대조해 겹치면 이름을 바꾼다. 모듈 앵커가 유일해도 전역 단일 클래스(ex. `.txt_desc{}`)는 새 요소에 그대로 먹는다
  - 가이드·참고 HTML 이 정해 둔 이름(ex. `inner_comm`, `tit_main`)도 예외가 아니다. 바꾼 이름에도 원래 규칙을 적용한다(컨테이너는 바꾼 이름 하나만 쓴다)
  - `blind` 만 예외 — 사이트의 `.blind` 가 같은 숨김 텍스트(IR) 역할이면 그대로 쓴다. 화면에서만 감추고 스크린 리더는 읽게 하는지로 판단한다(`display: none` 처럼 스크린 리더도 못 읽게 하거나 다른 용도로 쓰이면 다른 역할)
  - 사이트에 `.blind` 가 없거나 역할이 다르면 `references/css/reset_rw.css` 의 `.blind` 정의를 새 CSS 로 옮긴다(`legend`·`caption` 은 빼고, 이름이 겹치면 바꿔서)
- **이름으로 못 피하는 영향** — 요소 셀렉터(`p{}`, `ul li{}`)나 조상 기반 규칙은 사이트 CSS 를 불러온 브라우저에서 계산 스타일로 확인한다
- **리셋** — 기존 사이트에는 리셋이 이미 있으니 `css-writing-guide.md` Reset 절처럼 묻지 않고, 불러온 사이트 CSS 를 리셋으로 본다. 값 표기 절의 "이미 적용된 속성은 다시 선언하지 않는다"도 UA 기본값이 아니라 그 CSS 가 적용된 상태를 기준으로 판단한다
- **새로 넣지 않는 것** — 리셋·요소 셀렉터·사이트 래퍼에 거는 전역 규칙(ex. 한글 줄바꿈의 `.wrap`)·폰트·아이콘·라이브러리 CSS. 로컬에선 멀쩡해 보여도 합치는 순간 다른 페이지가 바뀐다
- **아이콘·슬라이드** — 사이트가 이미 가진 수단으로 만든다. 사이트 CSS 목록(아이콘 폰트·스프라이트)과 페이지가 불러오는 스크립트(슬라이드 라이브러리)에서 찾고, `html-structure-guide.md` 의 Font Awesome·Swiper 전제와 `swiper.html` 구조는 쓰지 않는다. 사이트에 그 수단이 없으면 사용자에게 확인한다
