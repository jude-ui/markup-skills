# create-html-css-code

## Info
- html/css 코드를 작성할 때 참고하기 위한 스킬
- **코드를 어떤 스타일로 적는지만** 담는다. 시안 읽기는 `reading-figma`·`reading-img`, 시안을 코드로 옮기는 흐름은 `design-to-markup` — 시안이 없어도 이 스킬만으로 작성할 수 있다
- 시안도 디자인 방향도 없이 작성할 때는 프로젝트에 이미 있는 스타일(리셋·공통 CSS·색 변수)을 쓰고, 없으면 구조가 드러날 만큼만 꾸민다. 화이트 배경, 제목 속 이탤릭 강조 단어, '01/02/03' 번호 섹션 라벨, 모노스페이스 라벨, 알약형(pill) 버튼은 넣지 않는다

## 작업 순서

1. HTML 코드 작성시 `references/html-structure-guide.md`를 읽어 확인
2. CSS 네이밍 작성시 `references/css-naming-guide.md`를 읽어 확인
3. CSS 코드 작성시 `references/css-writing-guide.md`를 읽어 확인

**기존 사이트 화면 소스를 긁어온 로컬 페이지에서 작업하면** 1번 전에 `references/existing-site-guide.md` 를 읽는다. 클래스명·아이콘·슬라이드를 가이드 기본값으로 정한 뒤에 읽으면 HTML 을 다시 써야 한다
