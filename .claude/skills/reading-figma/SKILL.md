# reading-figma

피그마 시안에 **무엇이 있는지 알아내는 법**만 담는다.

```
읽기   reading-figma (이 스킬)      시안에 무엇이 있는지 알아낸다
흐름   design-to-markup            알아낸 것을 코드로 어떻게 바꿀지 정한다
쓰기   create-html-css-code        바꾼 코드를 어떤 스타일로 적을지 정한다
```

## 읽는 순서
1. **시안 읽기** — `references/reading-figma.md` 의 도구 선택·놓치기 쉬운 것·이미지 에셋
2. **구현과 대조** — 마크업을 만든 뒤 `references/reading-figma.md` 의 "구현과 대조" 절

프로젝트 전용 애드온 스킬이 함께 불렸으면(ex. 시안이 그 프로젝트의 피그마 컴포넌트 라이브러리로 그려진 경우) 그 애드온이 읽기 단계에 더하는 문서도 함께 읽는다.
