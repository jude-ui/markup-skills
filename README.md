# markup-skills

HTML/CSS 퍼블리싱 스킬을 담은 저장소입니다. 스킬은 `.claude/skills/` 에 들어 있고, 폴더를 그대로 읽어 씁니다.

> 문서 최종 업데이트: 2026-11-17

## 들어 있는 스킬

| 스킬 | 하는 일 |
|---|---|
| `create-html-css-code` | HTML/CSS 를 쓸 때의 규칙(구조·네이밍·CSS 작성), 시안(피그마·이미지) 읽기·마크업으로 옮기기·구현 결과 대조 |

## 쓰는 법

- **이 저장소에서 작업할 때** — 저장소를 열면 `.claude/skills/` 의 스킬이 그대로 잡힙니다.
- **다른 프로젝트에서 쓸 때** — `.claude/skills/create-html-css-code/` 폴더를 그 프로젝트의 `.claude/skills/` 로 복사합니다.
- **모든 프로젝트에서 쓸 때** — 같은 폴더를 `~/.claude/skills/` 로 복사합니다.

스킬 문서를 고친 뒤에는 새 세션을 열면 반영됩니다.

## 구조

```
.claude/skills/
└── create-html-css-code/   SKILL.md · references/(가이드·CSS/HTML 샘플·design/ 시안 읽기·옮기기·대조) · scripts/(swiper.js·measure.py)
```
